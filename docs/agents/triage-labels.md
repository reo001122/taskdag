# トリアージラベル

トリアージの5つの標準ロール。GitHub issue には同名のラベルとして付ける。

| ラベル             | 意味                                       |
| ------------------ | ------------------------------------------ |
| `needs-triage`     | メンテナがまだ評価していない                |
| `needs-info`       | 報告者からの追加情報待ち                    |
| `ready-for-agent`  | 仕様が確定していて、AFK エージェントに渡せる |
| `ready-for-human`  | 人間による実装が必要                        |
| `wontfix`          | 対応しない                                  |

Skill がロール名(例: 「AFK-ready のトリアージラベルを付ける」)に言及したら、この表の対応するラベル文字列を使う。
